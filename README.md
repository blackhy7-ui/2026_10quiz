# AI 식물 주치의 – 내 다육이를 부탁해

학교 축제와 집에서 사용하는 모바일 정적 웹사이트입니다. 별도 빌드, 회원가입, API 키, 서버 DB가 필요하지 않습니다.

## 두 가지 메뉴

- **부스 체험**: 난이도별 퀴즈 → 체험권 → 그림으로 보는 만들기 7단계 → 실물 코인·뽑기·쿠폰 제출·선물 안내
- **AI 주치의**: 브라우저 사진 비교 + 흙·잎·마지막 물주기·배수구 기반 관리 안내

두 메뉴는 독립적입니다. 퀴즈는 선택 난이도 5문항(상식 3 + 수학 2), 4지선다입니다. 오답 재도전 후 전 문항을 정답으로 완료하면 체험권이 표시됩니다. 정답 해설을 읽고 다음 버튼으로 진행합니다. 체험권은 사용 여부 검증을 하지 않으므로 실물 운영 확인은 운영자가 담당합니다.

## 로컬 실행

저장소 루트에서 `python3 -m http.server 4173`를 실행하고 브라우저로 확인합니다. ES 모듈 때문에 HTML을 파일로 직접 열지 마세요.

## GitHub Pages 배포

1. 이 저장소의 `index.html`과 `assets` 폴더를 함께 커밋하고 `main` 브랜치에 업로드합니다.
2. GitHub 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. 브랜치는 **main**, 폴더는 **/(root)** 로 선택해 저장합니다.
4. 배포 완료 후 GitHub가 표시하는 HTTPS 주소로 접속합니다. 코드는 상대 경로를 사용하므로 프로젝트 하위 주소를 지원합니다.
5. 실제 Android Chrome / iPhone Safari에서 촬영·앨범·퀴즈·체험권·모델 다운로드를 확인합니다.

현재 작업에서 원격 업로드와 Pages 게시를 자동으로 실행하지 않습니다. `.nojekyll`로 정적 파일 배포를 명시합니다.

## 사진과 AI

- Transformers.js 3.8.1(Apache-2.0), Xenova/clip-vit-base-patch32 모델(MIT 표기)을 사용하는 실제 zero-shot-image-classification입니다. 재배포 시 해당 프로젝트의 라이선스를 확인·준수하세요.
- 모델은 분석 버튼을 눌렀을 때만 로딩합니다. `cdn.jsdelivr.net`, `huggingface.co`와 Hugging Face의 모델 파일 리디렉션 호스트 접근이 필요합니다.
- 첫 모델 로딩은 큰 다운로드 및 기기 메모리를 요구합니다. 20~30명 동시 최초 다운로드 시 행사 Wi-Fi 부하를 사전 확인하세요. 브라우저의 모델 캐시가 재사용될 수 있지만 오프라인 동작은 보장하지 않습니다.
- 사진은 브라우저 메모리에서 최대 변 1024px로 축소하고 추론합니다. 사진 업로드·사진 localStorage 저장·분석 추적 요청은 없습니다. 외부 서버에는 모델/라이브러리 파일 요청만 합니다.
- CLIP 점수는 선택한 설명들 사이의 **상대 유사도**입니다. 건강·질병·수분 상태의 확률이 아닙니다. 점수 차이가 0.1 미만이거나 비식물 설명이 1위인 경우 판단을 보류합니다. 0.1은 진단 성능을 보장하는 검증 기준이 아닌 보수적 UI 규칙입니다. 그 외에도 올바른 특징 인식을 보장하지 않습니다.
- 색과 눈에 보이는 주름 설명만 비교합니다. 촉감·뿌리 상태·질병을 인식한다고 주장하지 않습니다. 오류 시 결과를 생성하지 않습니다.
- 기록(날짜/흙/잎/배수구)과 체험권은 이 기기 localStorage에만 저장합니다. 관리 화면의 기록 삭제는 체험권과 별개입니다. 공유 휴대폰에서는 브라우저 사이트 데이터로 전체 초기화할 수 있습니다.

## 원본과 변경 근거

첨부된 기존 HTML 5개를 분석하고 원본은 수정하지 않았습니다. 기존의 정답 재도전·체험권·힌트·관리 규칙·브라우저 추론을 통합했습니다. 사용자가 요청한 2개 난이도와 전 문항 정답 완료 기준을 적용했습니다. 기본 퀴즈 5개 핵심 개념을 새 퀴즈에 반영했습니다.

기존 사진판은 실제 CLIP을 사용했지만 점수를 숨긴 채 모든 라벨을 표시하고, 흙 입력에 따라 같은 안내를 반복했습니다. 현재는 실제 점수 공개, 비식물 비교, 판단 보류, 사진 교체 시 초기화, 촬영·앨범 분리, 오류 유형 구분을 제공합니다.

## 검증 범위

`VALIDATION.md`를 확인하세요. 실물 스마트폰 추론 성능·특징 구분 정확도·축제 네트워크 환경은 별도의 현장 확인이 필요합니다. 모델이 정확하지 않은 경우 사진 없는 관리 안내를 사용하세요.

## 자동 검사

`node --test tests/core.mjs`로 퀴즈 데이터와 관리 안내 규칙을 검증할 수 있습니다. 브라우저 검사 방법과 실제 통과 범위는 `VALIDATION.md`에 기록했습니다. 사진 판별 성능 검증을 대신하는 테스트는 아닙니다.
