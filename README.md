# 내 다육이를 부탁해

2026 문경교육대축제 문경서중학교 부스와 집에서 사용하는 무료 모바일 웹사이트입니다.

## 부스 체험

난이도 선택 → 퀴즈 5문항(상식 3 + 수학 2, 4지선다) → 체험권 → 만들기 7단계 → 코인·뽑기·쿠폰 제출·선물 안내. 오답은 다시 선택하고 전 문항 정답 완료 후 체험권을 표시합니다. 체험권은 실물 운영자가 확인하며 일회성 사용 인증은 하지 않습니다.

## 집에서 다육이 돌보기

- **내 다육이:** 외형 그림 선택, 별명, 마지막 물주기 날짜, 오늘 물주기 기록.
- **물주기 확인:** 속흙·잎 상태·배수구를 직접 선택하고 관리 안내를 확인합니다. 날짜만으로 물주기를 확정하지 않습니다.
- **관리법:** 선택한 외형에 맞는 햇빛·물주기·주의 안내.
- 날짜 변경과 별명·상태 선택은 즉시 브라우저 localStorage에 자동 저장합니다. 오늘 물주기는 확인 후 이력에 추가하며 같은 날 중복 기록은 막습니다.
- 직접 입력한 날짜는 마지막 물주기 날짜만 변경하며 과거 이력을 자동 생성하지 않습니다.
- 기존 succulent-home-v2 / succulent-care-v1 기록은 새 저장 형식으로 읽어옵니다. 기록 삭제 시 구형 기록도 지워 재등장을 막고 체험권은 유지합니다.
- 한 브라우저에서 한 화분을 관리합니다. 다른 사람·다른 기기와 동기화하지 않습니다. 공용 기기에서는 같은 기록을 공유하고, 시크릿 모드·사이트 데이터 삭제 시 기록이 사라질 수 있습니다.
- 그림은 외형을 설명하는 삽화이며 실제 식물 사진이나 확정된 품종 정보가 아닙니다.

**사진 업로드·촬영·AI 추론·모델 다운로드 기능은 제거했습니다.** 유료 API, 회원가입, 서버와 DB가 필요하지 않습니다. 외부 모델 제공처에 요청하지 않습니다.

## 로컬 실행과 검사

저장소 루트에서 `python3 -m http.server 4173`를 실행합니다. ES 모듈을 사용하므로 HTML을 파일로 직접 열지 마세요.

- `node --test tests/core.mjs`: 퀴즈와 관리 규칙.
- Playwright가 있는 환경에서 `node tests/browser.mjs`, `node tests/compact.mjs`, `node tests/mobile-pages.mjs` 실행.
- 외부에 설치한 Playwright는 `PLAYWRIGHT_MODULE=/tmp/succulent-check/node_modules/playwright/index.mjs`처럼 지정할 수 있습니다. `BASE_URL` 기본값은 로컬 검증용 서버 주소입니다.
- 기본 Chromium 경로는 `/usr/bin/chromium`입니다. 검사 기록은 `VALIDATION.md`를 참고하세요. 과거 검증 기록의 AI 관련 내용은 제거 전 버전에 대한 기록입니다.

## GitHub Pages

1. `index.html`, `assets/`, `.nojekyll`을 함께 main에 업로드합니다.
2. 저장소 Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. 배포 완료 후 GitHub가 안내하는 HTTPS 주소에서 확인합니다.

프로젝트 하위 경로를 지원하며 별도 빌드가 필요 없습니다. 실행 파일에는 내용 기반 버전을 붙여 이전 파일 캐시가 재사용되는 것을 줄입니다.
